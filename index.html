                                              Backup & Restauro
                                              O backup exporta todos os dados do AVICONTROL (lotes, mortalidade, peso, ração, despesas, vendas e configuração do plano) para um único ficheiro JSON, que pode guardar como cópia de segurança. Antes de eliminar um lote ou restaurar um backup, o sistema cria automaticamente uma cópia de segurança interna dos dados atuais.
                                                🔑 Ferramenta do dono — códigos de licença
                                                Emita para o cliente depois de receber o pagamento. O mesmo código pode ser reutilizado — controle o pagamento do seu lado.
                                                📤 Restaurar Backup
                                                  ATENÇÃO: restaurar este backup irá substituir todos os dados atuais do AVICONTROL pelos dados do ficheiro. Será criada automaticamente uma cópia de segurança dos dados atuais antes de prosseguir.
